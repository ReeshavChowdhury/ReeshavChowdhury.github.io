# Reeshav Chowdhury — GitHub Pages

Personal research and open-source project website, linking to [Google Scholar](https://scholar.google.com/citations?user=WjMcQ4EAAAAJ&hl=en) and featuring [Veynremote](https://github.com/ReeshavChowdhury/Veynremote).

- Website: https://reeshavchowdhury.github.io/
- Project: https://reeshavchowdhury.github.io/veynremote/
- Hosting: GitHub Pages, `main` branch, repository root.

This is a static HTML/CSS/JavaScript site. There is no build step, analytics,
account system, or remote desktop service hosted here. The privacy demonstration
is an illustration, not a real remote-control session.

## Edit and preview

Edit `index.html`, `veynremote/index.html`, and the files in `assets/`.
Run `python3 -m http.server 8765` from the repository root and visit
http://localhost:8765/ . Changes pushed to `main` are published by GitHub Pages.

## Search discovery

Canonical URLs, social metadata, structured data, and `sitemap.xml` are included.
They help describe the website but do not guarantee Google indexing or ranking.

To monitor indexing, the site owner can add `https://reeshavchowdhury.github.io/`
as a URL-prefix property in [Google Search Console](https://search.google.com/search-console),
verify it using Google's HTML file or HTML meta-tag method, and submit `sitemap.xml`.
The verification file or tag must be the exact one issued to the owner; no
verification token has been added or invented. After verification, use URL
Inspection to request indexing of the home and Veynremote pages.
