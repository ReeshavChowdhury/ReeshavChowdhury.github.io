Remote desktop / Ubuntu + Windows

Veynremote

Control Ubuntu from Windows in full color while the physical Ubuntu monitor goes black. Add authenticator verification and lock the desktop when you disconnect.

Ubuntu on XorgGoogle AuthenticatorAGPL-3.0
  • Physical screen blanking with a restoration watchdog
  • TOTP two-factor authentication and recovery codes
  • Auto-lock after the final viewer disconnects
  • Built on the original Veyndesk project

These pages document my projects and the changes behind them. Veynremote is an independently modified version of Veyndesk, whose contributors created the original remote desktop application.

This version adds Ubuntu display blanking, authenticator-based verification, and disconnect locking. The original history and AGPL license are preserved.
