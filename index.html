Remote desktop

A Veyndesk-based project adding Ubuntu physical-screen blanking, authenticator verification, and auto-lock after disconnect. An application project within this portfolio; it does not implement FHE.

Project details →
Homomorphic encryption

SEAL Lab

A browser-based Microsoft SEAL demo with exact BFV integer arithmetic and approximate CKKS vector addition, multiplication, and rotation. It runs locally with WebAssembly and includes optional public-key and ciphertext inspection.

Try the live demo ↗Source code →
Encrypted inference

Encrypted MNIST Lab

A browser-based CKKS demo that encrypts MNIST images, evaluates convolution, activation, and dense layers over ciphertexts with Microsoft SEAL WebAssembly, then decrypts predictions. Includes model-agreement and batch-accuracy results.

Try the live demo ↗Source code (private) →
